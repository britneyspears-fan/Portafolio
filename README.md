# Portafolio



**CONCEPTOS:**



HTML: Se utiliza para definir la estructura del proyecto.

CSS: Darle un diseño a lo que dijo en el HTML.

JavaScript: Se utiliza para que la persona pueda realizar acciones en el proyecto (encargo Newen).

MQTT: Conectar dispositivos físicos a plataformas de internet (como el encargo Estática de la nostalgia).

GitHub Pages: Crear repositorios. 

MediaPipe: Se utiliza para detectar gestos (Finger Paint).
